# Manual CUDA extension checklist for Pixal3D-ComfyUI.
#
# This file is documentation, not a universal install file. Do not blindly run
# `pip install -r requirements-cuda-manual.txt`; every wheel below must match
# your exact ComfyUI Python ABI, PyTorch build, CUDA runtime, platform, and GPU.
#
# Required from the existing ComfyUI stack:
#   torch
#   torchvision
#
# Attention prerequisite, install separately for your exact stack:
#   flash-attn               # provides flash_attn, or use FlashAttention 3 below
#   flash-attn-3 wheel       # provides flash_attn_interface
#   triton / triton-windows
#
# Required Pixal3D CUDA extensions:
#   flex_gemm_ap / flex_gemm
#   cumesh_vb / cumesh
#   o_voxel_vb_ap / o_voxel
#   drtk
#
# Optional CUDA extensions:
#   nvdiffrast
#   nvdiffrec_render
#
# Optional but needed for exact upstream Pixal3D NAF:
#   natten + libnatten
#
# Note: requirements.txt installs plain natten==0.21.6 as a baseline package.
# That is not enough for strict NAF unless:
#   python -c "import natten; print(natten.HAS_LIBNATTEN)"
# prints True.
#
# Not a replacement for NATTEN/NAF:
#   comfy-sparse-attn
# It dispatches sparse/variable-length attention for ComfyUI-style models, but
# does not provide NATTEN neighborhood-attention APIs or libnatten CUDA kernels.
#
# Example Windows stack discussed in docs:
#   Python 3.12
#   PyTorch 2.10.0+cu130
#   CUDA runtime 13.0
#
# The official NATTEN command for this torch/cuda tag is:
#   pip install natten==0.21.6+torch2100cu130 -f https://whl.natten.org
#
# This is the easy path for Linux/WSL NVIDIA installs. On native Windows,
# upstream points users to MSVC source builds. Verify with:
#   python -c "import natten; print(natten.__version__, natten.HAS_LIBNATTEN)"
#
# HAS_LIBNATTEN must be True for naf_mode=strict. If it is False, keep:
#   naf_mode=fallback_if_missing
#
# Full wheel notes:
#   docs/windows_wheels.md
